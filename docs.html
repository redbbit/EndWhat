使用文档

快速上手 · 本地模型配置 · 数据目录 · 常见故障

快速上手三步

  1. 安装：从 下载页下载安装版并运行安装向导。不需要管理员权限，装到当前用户目录。
  2. 安装可选组件与本地模型：安装向导里勾选「本地嵌入运行时（离线版，约 97 MB）」；本地对话模型需自备（如 Ollama + Qwen2.5）。嵌入模型权重 bge-m3（约 4.3 GB）需另行下载，程序内会给出引导。
  3. 首次启动：选择数据目录（可自选，默认 %LOCALAPPDATA%\EndWhat\data）+ 确认已年满 18 周岁 + 同意用户协议与隐私政策。

本地模型配置（Ollama）

程序默认走 Ollama 原生 HTTP API（http://127.0.0.1:11434），默认模型 qwen2.5:14b。

  1. 安装 Ollama：访问 ollama.com 下载安装。
  2. 拉取模型：在终端执行 ollama pull qwen2.5:14b
  3. 保持 ollama serve 在跑（默认端口 11434）。

⚠️ 当前限制（重要）：模型名与地址目前硬编码在 P1 的 config.py 里，设置中心暂无「改模型 / 改地址」的入口。LM Studio / llama.cpp / vLLM 等 OpenAI 兼容服务目前不直接支持（协议不同）。

嵌入模型权重（bge-m3，约 4.3 GB）

不随包分发。程序检测到缺失时会明确告知并给出下载入口，由你决定是否下载。绝不静默下载。

不安装的后果：记忆写入与语义检索不可用（界面会提示安装）；其余功能不受影响。

能力级路由配置

8 个能力（chat / tts / stt / image / web_search / plugin_summary 等）可各自选「本地」或某个云端档案；配置写在 <数据目录>\routing.json，密钥写在 secrets.json。

  • 默认没有任何云端档案，即默认全本地。
  • 你可以只把「语音合成」交给云端，让对话仍然跑在本机。
  • 云端调用失败会自动回落本地，并在结果里记录失败原因。

数据目录与备份 / 迁移

  • 默认：%LOCALAPPDATA%\EndWhat\data（首次启动可自选）。
  • 移动程序目录时，请一并移动 data_path.json，或重新指定数据目录。
  • 升级 / 替换程序不会删除你的数据。
  • 导出：程序内「关于 → 导出我的数据…」，导出为 ZIP（标准 SQLite + JSON，不加密）。
  • 卸载不会自动删除数据目录。需要彻底清除时，请在卸载后手动删除数据目录。

常见故障

  • Windows 11 找不到托盘图标：点任务栏「^」溢出区，找到「未竟之言」，右键「固定到任务栏」。
  • 端口占用：服务端占用 8000–8007（P8 只保留 8006 不监听），被占用时需自行处理。
  • 连不上 Ollama（OLLAMA_NOT_RUNNING）：通常是 ollama serve 没启动。
  • 提示模型不存在：执行 ollama pull <模型名>。
  • 记忆检索总是空 / 设置页显示「未安装」：可选组件或 bge-m3 权重没装。设置页「本地模型」有一键安装按钮。
  • 语音没声音：piper 或音色模型缺失，放 zh_CN.onnx + .json 到 <数据目录>\models\piper\。
  • 日志位置：<数据目录>\logs\server\
