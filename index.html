默认离线，隐私不是设置项，是默认值

🛡️ 不收集 · 不上传 · 加密

  • 不主动收集任何用户数据；不接入统计、埋点、广告 SDK。
  • 不把对话、记忆、角色数据上传到开发者服务器——我们没有这样的服务器。
  • 隐私财产以 AES-256-GCM 加密存储；密钥保存在数据目录下的 .key 文件（权限 600）。
  • 日志只记录事件类型与时间戳，不含你的对话与记忆内容。

☁️ 想用云端也行，由你开关

  • 可以只把"语音合成"交给云端，让对话仍然跑在本机。
  • 云端 API 密钥只保存在你本机，不随包分发、不进日志、不回显。
  • 一旦启用云端 API，该能力当次所需内容会发送给你选定的第三方服务商。
  • 如服务在境外，数据将传输至境外，请自行确认合规要求。如不接受，请保持全本地。
