本地优先与隐私

版本：v1.0 ｜ 最后更新：2026年10月

一句话结论：本软件默认完全离线，不主动收集您的数据。只有您主动开启云端 API 或联网搜索等功能时，才会产生网络请求，且只发送当次任务所需的字段。

一、我们不做什么

  • 不收集身份信息、通讯录、位置、设备标识；
  • 不接入使用行为统计、埋点或广告 SDK；
  • 不把对话、记忆、角色数据上传到开发者服务器（我们也没有这样的服务器）；
  • 不主动将您的数据用于训练；
  • 绝不静默下载模型或组件；
  • 不要求注册账号，因此也没有跨设备云同步。

二、本机保存什么

以下内容只写进您选定的数据目录（默认 %LOCALAPPDATA%\EndWhat\data，首次启动可自选）：

  • 对话记录、记忆条目（本机 SQLite 数据库与向量索引）；
  • 角色、属性、世界线、关系数据；
  • 立绘、生成的图片、头像；
  • 插件与设置文件；
  • 运行日志（仅事件类型/时间戳/错误信息，不含对话与记忆内容）；
  • 加密密钥 .key（权限 600，首次使用时本机随机生成）。

三、什么时候会出网（四类）

  1. 云端 API 调用 — 只对您显式路由到云端的能力，且只在该能力被使用时；
  2. 联网搜索 — 默认关闭；您打开后，只发送搜索关键词；
  3. 插件市场 — 只在您打开浏览或安装时；
  4. 检查更新 — 只在您点击检查、或您保持自动检查开启时。

除上述四类外，本软件不发起任何其他网络请求，也不包含任何统计、广告或崩溃遥测 SDK。

四、第三方 API 与跨境传输

云端 API 的密钥由您自行配置，仅保存在本机（%数据目录%\settings\secrets.json，权限 600）。一旦启用某能力的云端 API，该能力当次所需的数据会发送给您选定的第三方服务商，其数据处理方式由其隐私政策约束，我们无法控制。如您配置的服务在境外，数据将传输至境外，请自行确认合规要求。如不接受，请保持全本地设置。

五、第三方插件

第三方插件的数据访问行为由其自身负责。安装插件时程序会展示其权限声明，由您确认后授权。您可随时禁用或卸载插件；权限变更会记录在本地权限审计日志中。

六、数据导出与删除（您的数据可携带权）

  • 导出：程序内「关于 → 导出我的数据…」导出为 ZIP（标准 SQLite + JSON，不加密，便于迁移；请妥善保管）。
  • 删除：可直接删除数据目录中的文件；卸载程序不会自动删除数据目录。需要彻底清除时，请在卸载后手动删除数据目录——删除后不可恢复。

七、数据安全事件响应

本软件为单机运行，无服务器端 7×24 监控。安全问题的发现途径：您的反馈（2242858980@qq.com，标题注明"安全"）、安全社区与公开披露信息、以及本机自查线索（不含内容的操作日志、核心数据文件完整性校验、异常外联提示）。

一旦确认发生影响您数据安全的事件，我们将在 72 小时内通过 应用内弹窗 + 电子邮件（若您曾提供）+ 官网公告 三种方式通知您，并说明事件内容与影响、已采取的处置措施、您可自主采取的防范建议以及联系方式。

由于数据存储在您自己本机，数据目录本身的失窃风险需您自行防护（设置电脑登录口令、做好备份、不使用来源不明的插件）。

八、AI 内容标识

对话界面固定标注"AI 生成内容"；导出的图片/文本保留显式标识（「AI 生成」水印）与隐式标识（文件元数据中的生成合成内容属性、服务提供者编码等），符合《人工智能生成合成内容标识办法》的要求。

九、未成年人

本软件不面向未成年人。首次启动需确认已年满 18 周岁；如未满 18 周岁请停止使用。

十、联系方式与安全通知时限

  • 邮箱：2242858980@qq.com（安全问题请注明"安全"）
  • 官网：https://redbbit.github.io
  • 安全事件通知时限：确认后 72 小时内
  • 一般咨询回复时限：15 个工作日内
